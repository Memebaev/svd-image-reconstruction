# SVD Image Reconstruction
Приложение на Python для демонстрации сингулярного разложения матриц (Singular Value Decomposition, SVD) на примере изображений.
Программа позволяет загрузить изображение с компьютера или по URL, преобразовать его в оттенки серого и восстановить изображение с использованием разного количества сингулярных компонент. Благодаря этому можно наглядно увидеть, как количество компонент влияет на качество изображения и уровень потери деталей.
## Возможности
* загрузка изображения с компьютера
* загрузка изображения по URL
* преобразование изображения в оттенки серого
* восстановление изображения методом SVD
* одновременное сравнение нескольких вариантов восстановления
* интерактивное приближение и отдаление изображения
* изменение количества сингулярных компонент с клавиатуры
* просмотр отдельных участков изображения при большом увеличении

## Принцип работы
После запуска появляется диалог выбора источника изображения.
Пользователь может выбрать изображение с компьютера либо указать URL изображения. Загруженное изображение преобразуется в оттенки серого, после чего представляется в виде матрицы чисел. Значения матрицы соответствуют яркости пикселей.
Затем программа использует следующие значения `k`:
```python
ks = [100, 50, 20, 10, 5]
```
`k` определяет количество сингулярных компонент, которые используются для восстановления изображения. Чем больше компонент используется, тем больше информации исходной матрицы сохраняется. При уменьшении `k` матрица становится более низкоранговой, поэтому мелкие детали постепенно теряются.
### SVD-разложение
Для выбранной области изображения сначала вычисляется средняя яркость:
```python
region_centered = region - region.mean()
```
Из изображения вычитается среднее значение, после чего выполняется SVD:
```python
U, S, VT = np.linalg.svd(
    region_centered,
    full_matrices=False
)
```
В результате исходная матрица представляется в виде:

$$
A = U\Sigma V^T
$$

где:
* `U` — левая ортогональная матрица;
* `Σ` — диагональная матрица сингулярных значений;
* `Vᵀ` — транспонированная правая ортогональная матрица.
После этого сохраняются только первые `k` компонент:
```python
Ak = U[:, :k_val] @ np.diag(S[:k_val]) @ VT[:k_val, :]
```
Получается приближённая низкоранговая матрица:

$$
A_k = U_k\Sigma_kV_k^T
$$

После восстановления обратно добавляется средняя яркость изображения:

```python
Ak += region.mean()
```

В конце значения ограничиваются диапазоном от `0` до `255`, чтобы они соответствовали допустимым значениям яркости пикселей:

```python
return np.clip(Ak, 0, 255)
```

Таким образом, функция `svd_re()` выполняет полный цикл: центрирование изображения → SVD-разложение → выбор первых `k` компонент → восстановление → возврат среднего значения → ограничение яркости.

## Визуализация

Программа создаёт окно с пятью областями отображения:

```python
fig, axs = plt.subplots(1, 5, figsize=(24, 6))
```

Каждая область соответствует своему значению `k`:

```text
k=100   k=50   k=20   k=10   k=5
```

Для каждого значения программа заново восстанавливает текущий фрагмент изображения и отображает его в оттенках серого.

Это позволяет непосредственно сравнить качество изображения при разном количестве сохранённых компонент.

### Влияние `k`

| Значение `k` | Результат                                            |
| -----------: | ---------------------------------------------------- |
|  Большое `k` | Изображение максимально близко к исходному           |
|  Среднее `k` | Часть мелких деталей теряется                        |
|    Малое `k` | Изображение становится более сглаженным и упрощённым |

Главная идея метода заключается в том, что большая часть значимой информации изображения может содержаться в относительно небольшом количестве сингулярных компонент.

## Интерактивный зум

Приложение поддерживает увеличение и уменьшение изображения.

Используются следующие параметры:

```python
zoom = 1.0
min_zoom = 1.0
max_zoom = 20.0
```

При увеличении программа не масштабирует всё изображение целиком, а выбирает меньшую область вокруг текущего центра просмотра. Размер этой области рассчитывается относительно текущего значения `zoom`.

Это позволяет исследовать отдельные части изображения и сравнивать, как SVD сохраняет детали на разных уровнях увеличения.

## Управление мышью

### Левая кнопка мыши

Левая кнопка увеличивает изображение в точке, по которой был выполнен клик:

```text
ЛКМ - приблизить
```

Координаты точки клика преобразуются в координаты исходного изображения, после чего выбранная область становится новым центром просмотра.

### Правая кнопка мыши

Правая кнопка уменьшает масштаб:

```text
ПКМ - отдалить
```

Минимальное значение масштаба ограничивается `1.0`. При полном возврате к исходному масштабу центр изображения также возвращается в центр исходного изображения.

## Управление клавиатурой

Количество сингулярных компонент можно изменять непосредственно во время работы программы.

```text
Стрелка вверх - увеличить k на 5
Стрелка вниз - уменьшить k на 5
```

При уменьшении значение `k` не может стать меньше `1`. После каждого изменения все пять вариантов изображения пересчитываются и отображаются заново.
